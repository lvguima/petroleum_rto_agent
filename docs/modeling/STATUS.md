## 当前风险与待决事项

1. 现有伪组分和设备参数仍是低可信度工程初值，M1～M3 只能证明模型内部合理性。
2. case_20260604 来自 DCS 图片和弱时间对齐化验，不能作为现场动态精度验证。
3. DCS 压力暂按表压处理并转换为绝压，该假设需要后续现场确认。
4. .venv 缺少 setuptools，正式打包或可编辑安装前需要补齐；当前源码运行不受影响。
5. 仓库尚无 Git 基线提交，运行结果暂不能追溯到提交哈希，只能追溯到输入指纹和文件状态。
6. M3 为保持最小闭环模型规模，三条侧线不另设未有数据支撑的容器库存；侧线温度有一阶热惯性，侧线流量则按塔分配代数计算。
7. 冷凝油气分配及塔温响应的五个幅值系数是仅适用于约 ±5% 扰动的低可信工程初值，现有单个 M2 点无法识别；取得时间对齐现场动态数据前不得声明预测精度。
8. M3 所有运行结果都由结果契约强制标记 `synthetic=true` 和 `data_origin=M3_open_loop_simulation`；这只能防止来源混淆，不能替代未来的现场精度验证。
9. 动态产品质量代理已可从时间序列输出，但仍继承 M1 伪组分与物性参数的低可信度，只能作为方向性观察量，不能当作现场化验预测值。
