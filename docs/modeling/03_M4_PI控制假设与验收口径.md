# M4 PI 控制假设与验收口径

_本文只约束 CDU Mini Loop 的 M4 合成 PI 控制闭环。M4 复用 M3 的 54 维植物状态、物理方程和守恒门禁，不新增现场保护、阀门特性、优化器或 DCS 接口。总体边界见 [M0～M7 实施方案](./01_CDU_Mini_Loop实施方案.md)。_

---

## 📋 范围与可信度边界

M4 的交付对象是“独立数字 PI 控制器＋零阶保持命令＋M3 植物积分＋闭环性能门禁”。控制器状态不得写入或改变 M3 已冻结的 54 维 `DynamicState`，闭环结果必须单独标识为 M4 合成仿真。

- 三个所谓“液位”没有容器截面积、密度—高度关系或现场量程支撑，统一定义为库存代理：`当前库存 / M3 名义库存`。控制器使用滞后后的库存传感器值，安全门禁检查真实库存比。
- 新鲜进料和炉前流量没有独立传感器状态，首版把对应执行机构实际流量作为理想测量；不包含流量变送器的额外滞后、偏置和噪声。
- PI 输出是流量或热负荷命令，不是真实阀位。输出上下限和变化率是低可信、版本化的合成局部试验包络，不是现场阀门行程、设备极限或安全保护值。
- M3 的执行机构一阶滞后只保留一次。M4 控制命令限幅器不得复用含一阶动态的 `ActuatorSpec`，以免形成非预期双重执行器动态。
- M4 只声明局部约 `±5%` 扰动下的数值闭环能力，不声明现场整定、动态预测精度或可投用控制策略。

## 🔗 七个主回路与操纵量所有权

每个操纵量恰好由一个主回路拥有。回流量、冷凝负荷、第二和第三循环取热保持独立名义设定；闭环场景不得直接改写受控操纵量。

| 回路标识 | 被控量与归一化尺度 | 操纵量 | 作用方向 | 初始整定 `Kp / Ti` |
| --- | --- | --- | --- | ---: |
| `feed_flow` | 实际进料执行器 / 名义进料 | `fresh_feed_flow_kg_s` | direct | `1 / 8 s` |
| `flash_inventory` | 闪蒸罐库存传感器 / 名义库存 | `flash_liquid_outflow_kg_s` | reverse | `2 / 600 s` |
| `furnace_temperature` | 炉出口温度传感器 / 名义温度 | `furnace_fuel_duty_w` | direct | `4 / 180 s` |
| `top_pressure` | 塔顶绝压传感器 / 名义绝压 | `top_gas_vent_kg_s` | reverse | `8 / 1200 s` |
| `reflux_inventory` | 回流罐库存传感器 / 名义库存 | `gasoline_draw_kg_s` | reverse | `4 / 700 s` |
| `bottom_inventory` | 塔底库存传感器 / 名义库存 | `residue_draw_kg_s` | reverse | `3 / 800 s` |
| `top_temperature` | 塔顶温度传感器 / 名义温度 | `pump_around_1_duty_w` | reverse | `8 / 450 s` |

`direct` 表示正误差时操纵量增加，`reverse` 表示正误差时操纵量减少。配置只保存正数增益和明确动作，避免负号约定歧义。不得增加侧线液位回路，因为 M3 没有显式侧线容器库存。

## ⚙️ 数字 PI、斜坡和抗饱和

所有回路使用名义点归一化：

`e = (SP_ramped - PV) / PV0`

`u_raw = bias + action_sign * Kp * e + I + FF`

其中 `action_sign` 对 direct 为 `+1`，对 reverse 为 `-1`；`u`、`bias`、`I` 和 `FF` 均为相对名义操纵量的无量纲比值。每个控制时刻只更新一次控制器，区间内命令零阶保持。RK4 的四个子阶段只能调用植物方程，不能修改积分项。

设控制间隔为 `Δtc`，积分增量以当期误差计算，并用最终经过幅值和变化率限制后的输出做 back-calculation：

`I_next = I + action_sign * Kp / Ti * e * Δtc + (u_limited - u_raw) / Taw * Δtc`

设定值斜坡和输出变化率都按“名义尺度每秒的分数”限制。幅值与速率同时触发时，以最终合法输出参与抗饱和。所有尺度、时间常数、输出和状态必须有限；PV0 与 MV0 必须严格为正，名义输出必须严格位于上下限内部。

初始化自动模式时令 `SP = PV = PV0`、`u = u0`，并回算 `I = u/u0 - bias - FF - P`，首个输出必须严格等于 M3 基准命令。手动转自动采用同一回算，保证切换瞬间无跳变；自动转手动默认跟踪当前合法输出。

## 🔥 炉温流量前馈

炉温前馈使用闪蒸罐实际出料执行器作为炉前流量 `F`，不用未来的进料设定值。设名义燃料负荷为 `Q0`、炉效率为 `η`、热损失为 `Qloss`、名义炉前流量为 `F0`：

`Qff = [Qloss + (η * Q0 - Qloss) * F / F0] / η`

PI 使用 `FF = Qff / Q0 - 1` 修正名义偏置。该式在名义点严格返回 `Q0`；当前案例炉前流量增加 5% 时前馈燃料约增加 4.70%，剩余温度偏差由 PI 修正。

## ⏱️ 控制时刻与事件因果性

- 首版显式控制周期为 1 s，与植物积分步长独立。比较 `dt = 1 s` 和 `0.5 s` 时控制周期保持 1 s。
- 积分端点取名义输出网格、完整控制周期时刻和设定值事件时刻的有序并集；输出网格包含精确场景终点，但不足一个完整控制周期的终点不能被追加成控制动作。
- 数学上等价的浮点时刻按场景时长相关容差合并，例如 `0.3` 与 `0.30000000000000004` 只形成一个积分端点；容差组以组首时刻锚定，不做可能吞掉后续事件的传递式链合并。近零事件归一到 `t=0` 且只执行一次；重合时保留精确输出网格时间并同时处理控制/事件语义。
- 非网格事件先用旧设定值和旧命令完成事件左侧植物积分，再应用事件并计算未来区间输出。事件后的新误差不得乘以事件前已经过去的时间追溯修改积分项。
- 设定值斜坡在事件处连续启动；稳定时间从斜坡到达最终目标后开始计算。
- 基准阶段指标使用严格 `time < event_time` 的样本，不能把事件时刻的右连续新设定值误计入基准窗口。

## 📦 配置、场景与结果契约

控制配置独立于现有模型配置，防止改变 M0～M3 输入指纹。配置必须严格验证：七个必需回路齐全、PV/MV 白名单正确、MV 唯一、动作正确、数值有限、名义输出严格位于包络内部、版本与整定案例兼容。低层闭环入口也必须把控制/场景声明的模型、参数集、配置和案例版本与实际 M3 植物来源版本交叉核对，不能只验证两份 M4 配置彼此一致。

首版合成输出包络为：

| 操纵量 | 下限 / 名义 | 上限 / 名义 | 说明 |
| --- | ---: | ---: | --- |
| 进料、闪蒸出料、汽油采出、渣油采出 | 0.8 | 1.2 | 给 +5% 终态留出局部试验余量 |
| 燃料负荷 | 0.8 | 1.15 | 避免把高燃料命令伪装成安全可用范围 |
| 塔顶放空、第一循环取热 | 0.5 | 1.5 | 仅为合成数值试验包络 |

闭环场景事件目标必须是 `loop_id.setpoint_ratio`，不能直接写 M3 的受控操纵量。标准场景为 7200 s、600 s 时把 `feed_flow` 最终设定值改为 1.05；进料斜坡率为 0.001 nominal/s。

结果必须强制包含：

- `simulation_stage=M4`、`synthetic=true`、`data_origin=M4_closed_loop_simulation`；
- 软件、模型、参数集、配置、案例、场景和控制器版本；
- M3 源指纹、控制配置指纹及完整 M4 输入指纹；
- 每个样本的植物状态、11 个命令、M3 评价与累计守恒；
- 七路 SP 目标/斜坡值、当前样本 PV/误差、上次控制决策 PV/误差、P、I、FF、原始/受限输出、模式、幅值/速率饱和标志；非控制输出点只刷新当前样本 PV/误差，不伪造一次新 PI 决策；
- 失败阶段、失败时刻和最后有效端点。

结果契约还必须执行以下可自证一致性检查：

- 样本覆盖声明的每个输出网格时刻和完整控制周期时刻，事件额外端点可以保留；成功结果不得通过删除中间帧绕过 IAE、饱和或窗口指标。
- 每帧恰好包含 11 个植物命令和 7 路控制记录；七路当前 PV/输出与固定配对的植物传感器、执行器和命令一致，四个未由 PI 拥有的命令全程保持首帧名义值。
- 当前/决策误差、物理/归一化输出、自动模式的 `bias + P + I + FF`、非炉温零前馈和幅值/速率限制标志与记录内数值相互一致；规则控制时刻的决策 PV/误差必须刷新为当前值。
- 成功结果七路全程处于自动模式，末帧不得饱和；可直接从样本重算的 IAE、最终误差、总饱和时长和最长连续饱和时长必须与性能记录一致。
- 累计衡算必须由首帧库存、末帧库存及末帧累计进出量逐字段重建，并按所带容差重新检查每帧瞬时/累计守恒；门禁布尔值不能替代数值证据。
- 失败时刻不得早于最后有效端点；植物执行、七路性能和守恒门禁必须与已保留样本、累计账本及是否到达场景终点一致。

植物积分成功不等于 M4 验收成功。闭环 `success` 必须恰好包含并通过植物执行、植物守恒、自动投入无冲击、基准保持、七路性能和真实库存安全六项门禁，同时包含恰好七路通过的性能结果；零增益、错误方向、手动回路、截短指标窗口、规则帧缺失或偶然末帧进带都必须失败。

## ✅ M4 首版验收门槛

| 验收项 | 可自动判定的通过口径 |
| --- | --- |
| 自动投入 | 七个基准命令首个控制动作相对 M3 名义值的冲击 `<= 1e-12 × max(abs(u0), 1)` |
| 基准保持 | 事件前末段各 CV 归一化误差 `<= 1e-6`，归一化斜率 `<= 1e-8 /s` |
| 进料恢复 | SP 斜坡结束后 300 s 内进入最终目标 `±0.2%` 带并保持 |
| 库存恢复 | 三个库存代理在 3600 s 内进入 `±0.5%` 带并满足驻留时间 |
| 温度与压力恢复 | 炉温、塔顶温度和压力在 3600 s 内进入 `±0.5%` 带并满足驻留时间 |
| 尾窗性能 | 必须完整覆盖最后 600 s；各 CV 在精确窗口左边界插值后的时间加权平均绝对归一误差 `<= 0.2%`，归一化斜率 `<= 1e-6 /s` |
| 库存安全 | 三个真实库存比全程位于 `0.8～1.2` 合成验收带；传感器在带内不能掩盖真实越界 |
| 饱和 | 饱和状态按左保持控制区间计时；任一连续幅值或速率饱和不超过 300 s，最后 600 s 与跨越其左边界的区间均无饱和，末帧也不得饱和 |
| 振荡 | 尾窗峰峰值与斜率门禁通过，不以最后一帧偶然进带判稳定 |
| 植物门禁 | 继承 M3 非有限、负库存、正绝压、正炉前流量、炉温上限及瞬时/累计守恒门禁 |
| 步长敏感性 | 控制周期固定 1 s；`dt=1 s` 与 `0.5 s` 的关键状态和命令在共同控制时刻满足 M3 的 0.5% 全程、0.2% 终点门槛 |
| 重复性 | 相同全部输入的两次运行，结果字典逐项相同 |

性能报告至少输出各回路归一化 IAE、超调、稳定时间、最终误差、尾窗平均绝对误差、尾窗斜率、峰峰值、饱和累计时长和最长连续饱和时长。跟踪指标使用每个输出端点的当前测量 PV，控制器 P/I 诊断保留上次实际决策值，库存安全使用真实状态。短于配置窗口的轨迹必须明确失败，不能用现有样本把窗口静默截短。

## 🚫 前置拒绝与反例门禁

- 缺少必需回路、重复 MV、未知 PV/MV、动作与冻结配对不符、零或非有限尺度、名义点不在输出包络内部时，在 M2 或积分前拒绝。
- 场景直接改写受控 MV、未知回路、非法事件时间/数值、版本不兼容或伪装现场来源时，在 M2 或积分前拒绝。
- 声明的规则输出/控制网格缺帧、11 命令或七路记录不全、固定命令漂移、控制记录与植物证据矛盾、守恒账本脱离样本或失败时刻早于最后有效端点时，结果构造必须拒绝。
- 常量误差一个控制周期后的积分量必须只增加一次；不能因 RK4 四阶段变成四倍。
- 非对齐事件前的植物、命令和积分项不能受未来 SP 影响。
- 长时间幅值饱和或仅速率饱和后误差反向时，输出必须有界且能在规定时间内解饱和。
- 手动保持非名义输出再切自动时，切换瞬间输出必须连续。
- 零增益、极弱整定、错误方向、真实库存越界、未满足驻留时间、持续饱和或 M3 失败都必须使 M4 验收失败。

这些门槛只证明当前合成模型、当前整定和当前局部场景的闭环内部一致性。结果对象可以复核自身携带的记录、网格、性能和守恒证据，但不能脱离完整 `ControlConfig` 重算具体 Kp、输出限值、尾窗与稳定阈值，也不能脱离 `OpenLoopDynamicModel` 重新评价被任意篡改的 M3 状态—物理关系；真实闭环执行路径仍在每个 RK4 阶段和端点调用 M3 评价与硬约束门禁。
