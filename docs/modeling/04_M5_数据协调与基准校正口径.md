# M5 数据协调与基准校正口径

_本文只约束 CDU Mini Loop 的 M5 单案例数据协调与稳态参数校正。M5 使用现有只读现场资料和 M2 稳态求解器，不修改 M0～M4 基线配置，不拟合动态时间常数，也不宣称完成现场验证。总体边界见 [M0～M7 实施方案](./01_CDU_Mini_Loop实施方案.md)，数据可信度背景见 [常压蒸馏工艺及数据分析](../01_常压蒸馏工艺及数据分析.md)。_

---

## 📋 交付声明与范围

M5 的交付对象是一个可追溯、可重复的 `case_20260604` 对齐过程：原始资料保持只读，观测目录保存出处和不确定性，净边界流量先执行数据协调，最后只用协调后的三个产品流量校正两个局部可辨识的塔切割温度。

- 结果只能标记为 `case_alignment_only`，表示当前缩减阶模型与一套弱时间对齐现场资料的基准对齐。
- M5 不构成独立案例验证、跨原油验证、动态验证、现场仪表校验或可部署软测量证明。
- 原始截图手工读取值仍是现场观测，不是合成数据；协调值是带统计假设的派生现场数据，也不是合成仿真数据。模型预测必须单独标识来源。
- 任何未测出口都必须明确标为带先验的潜变量，不能伪装成 DCS 实测值。
- 基线模型、案例和伪组分文件保持不变；案例输入修订、协调结果与校正参数均写入新的版本化派生产物。

## 🧾 数据分层与观测契约

每条进入 M5 的观测必须保存以下字段，并通过严格类型、单位、有限值和枚举校验：

| 字段类别 | 必须保存的内容 |
| --- | --- |
| 身份 | 观测 ID、变量名、设备或边界角色、原始标签或表头 |
| 数值 | 原始值、原始单位、规范 SI 值、规范单位 |
| 时间 | 观测时刻或时间区间、时区、与基准时刻的偏移、对齐等级 |
| 来源 | 仓库相对路径、文件 SHA-256、页/工作表/单元格或截图定位、读取方式 |
| 质量 | 可信度、标准差或允许误差、质量标志、缺失/异常说明 |
| 用途 | 案例输入、协调测量、协调先验、校正目标、仅审查或暂不使用 |
| 语义 | 边界方向、是否内部循环、是否实测、是否由其他值推导 |

数据分为四层，后层不得覆盖前层：

1. `base_files/`：只读原始资料，不改名、不回写、不“清洗”原文件。
2. `data/catalog/`：规范化观测目录和源文件清单，保留原始值及哈希。
3. `data/gold/`：协调后的基准案例，逐项保留原始值、协调值、调整量、标准化调整量和衡算前后残差。
4. `reports/modeling/` 与版本化参数产物：模型运行、灵敏度、目标函数和审查结论。

## 🔄 净边界与数据协调

M5 首版固定装置净物料边界：

`fresh_feed + wash_water = gasoline + kerosene + light_diesel + heavy_diesel + residue + offgas + aqueous + brine`

- 塔顶回流、顶循、一中、二中及其他泵循环是内部物流，不进入装置净边界。
- 新鲜原油、注水和五个油品流量可作为测量项；未可靠测得的 `offgas`、`aqueous`、`brine` 只能作为带宽松先验的潜变量。
- 每个输入严格二选一：实测值 `z_i` 与版本化工程尺度 `σ_i`，或先验值 `p_i` 与尺度 `τ_i`。当前工程尺度是保守协调权重，不是仪表统计 `1σ`；禁止同一项同时伪装成实测与先验。
- 协调解要求所有流量有限且非负，并强制净边界等式闭合。

协调目标函数为：

`J_rec(x) = Σ_measured ((x_i - z_i) / σ_i)^2 + Σ_latent ((x_i - p_i) / τ_i)^2`

结果必须逐项输出 `raw/prior`、`reconciled`、`adjustment`、`normalized_adjustment`、是否内部排除及排除原因，同时输出协调前后边界残差、目标函数、观测目录指纹和协调配置版本。内部循环即使被收录用于审查，也不得改变净边界等式。

## 🧩 案例输入审计与派生案例

现有 `case_20260604` 和模型配置是 M0～M4 的低可信工程基线，不原地修改。M5 派生案例遵守以下处理：

- `flash_temperature` 使用有来源的相邻 DCS 观测修订，并同时保留原配置值与修订理由。
- `wash_water_ratio` 从设备固参语义迁移为案例操作覆盖；规范值由同一组截图中的注水与原油流量计算，保留分子、分母、时间差和不确定性。
- 回流比在标签未确认前保持 M0～M4 基线，不把候选 `FI-1010/FI-1012` 比值强制写入模型。
- 六伪组分进料组成保持现有低可信工程初值。它与五产品收率高度接近，若再用同一五产品流量反推组成会产生循环论证。
- 压力表压转绝压、截图读数误差和弱时间对齐继续作为显式假设，不因校正而升级可信度。

## 🎯 参数白名单、冻结项与目标函数

单案例首版只允许修改常压塔第三、第四切割温度：

| 参数 | 初值 | 允许边界 | 选择理由 |
| --- | ---: | ---: | --- |
| `column.cut_points_k[2]` | `583.15 K` | `568.15～598.15 K` | 主要改变常二/常三分配，局部灵敏度明确 |
| `column.cut_points_k[3]` | `638.15 K` | `623.15～653.15 K` | 主要改变常三/渣油分配，局部灵敏度明确 |

校正目标只使用协调后的 `light_diesel`、`heavy_diesel` 和 `residue` 质量流量。设模型预测为 `y_j(θ)`、协调目标为 `ŷ_j`、尺度为 `s_j`，参数先验为 `θ0`、正则尺度为 `r_k`：

`J_cal(θ) = Σ_j ((y_j(θ) - ŷ_j) / s_j)^2 + Σ_k ((θ_k - θ0_k) / r_k)^2`

每次候选参数评价都必须由 M2 回流求解器收敛，并通过总质量、各组分和盐守恒；不收敛或不守恒候选不得返回有效目标函数。

以下项目在 M5 首版全部冻结：前两个切割点、分离宽度、回流影响增益、六伪组分组成与物性、预热效率、炉效率、炉热损失、闪蒸关系、冷凝关系、质量代理修正、M3 动态时间常数和 M4 控制参数。原因包括单点不可辨识、与入选参数高度相关、缺少对应参数化结构或缺少时间对齐观测。

当前模型不存在独立的“闪蒸锐度”校正参数，M5 不为满足方案清单而临时发明一个参数。分离宽度与切割点局部相关，回流影响增益与回流比也高度相关，均不能在本单案例中同时求解。

## 📐 灵敏度、可辨识性与边界审查

校正前后都要用确定性有限差分计算三个目标对两个参数的局部灵敏度矩阵，并报告：

- 每个目标对每个参数的有量纲和归一化导数；
- 奇异值、数值秩、条件数和两列夹角余弦；
- 参数是否命中上下界、距边界余量及其审查结论；
- 初始与最终数据残差、正则项、总目标和相对改善；
- 未参与校正的观测及其模型偏差，不得在报告中省略不利数据。

首轮只读局部诊断显示三目标对两个切割点的导数列不共线、条件数约 `2.08`，因此适合作为实现种子；该诊断不是正式 M5 结果，正式数值必须由版本化配置和运行产物重新计算。

## 📦 版本与结果契约

一次有效 M5 运行至少携带并交叉校验：软件版本、模型结构版本、基线参数集版本、模型配置版本、案例版本、观测目录版本、协调配置版本、校正配置版本、派生参数集版本，以及所有输入文件和规范化配置的 SHA-256 指纹。

现场原始观测与协调值、M2 潜变量先验、M2 初始/最终预测必须逐节标明来源；含多类来源的顶层结果只能标记为混合来源，不能用单个 `synthetic=false` 把模型预测伪装成现场测量。

交付物至少包括：

- 版本化观测目录与源文件清单；
- 协调结果及完整净边界衡算；
- 案例输入覆盖和未采用观测清单；
- 两参数校正配置与派生参数集；
- 初始/最终目标、逐目标残差、灵敏度、相关性、边界和守恒证据；
- 机器可读 JSON 与面向审查的 Markdown 报告。
- 最后发布的成功套件清单，记录全部正式文件哈希与端到端结果指纹；缺少或哈希不符时不得把孤立参数文件视为有效交付。

同一输入组合重复运行必须得到逐项相同的结果字典和指纹。结果不得依赖当前工作目录、文件枚举顺序、随机初值或平台默认区域设置。

## ✅ M5 首版完成门槛

| 验收项 | 通过口径 |
| --- | --- |
| 溯源 | 每个参与协调或校正的值都有单位、时间、来源定位、文件哈希、读取方式、可信度和误差尺度 |
| 原始保护 | `base_files/` 不被修改；所有派生值写入版本化新文件 |
| 边界协调 | 净边界协调后残差在数值容差内为零，所有流量有限且非负；内部循环明确排除 |
| 表观偏差 | 可比同屏净烃流量的原始表观偏差不超过 `3%`；完整含水边界另按协调结果报告，不混用口径 |
| 参数范围 | 只改变白名单中的两个切割温度，二者均位于物理边界内；边界命中必须形成审查项 |
| 模型守恒 | 每个有效候选和最终解的 M2 总质量、组分和盐守恒达到既有数值容差 |
| 校正改善 | 最终总加权目标严格低于初始目标，并分别报告数据项与正则项；不允许用失败候选形成改善 |
| 可辨识性 | 正式有限差分矩阵具有两列有效秩，并报告条件数与列相关性；退化时必须失败或降级，不输出无标识参数 |
| 重复性 | 相同全部输入的两次协调、校正、灵敏度和序列化结果逐项相同 |
| 可信度 | 结果标记 `case_alignment_only`，明确单案例、弱时间对齐、低可信伪组分和未现场验证边界 |

若任何必需来源缺失、文件哈希变化、单位不兼容、协调问题不可行、M2 不收敛、守恒失败、目标未改善、参数越界或灵敏度退化，M5 必须保留失败阶段和原因，不生成伪装成有效的校正参数集。
