# CDU Mini Loop Python 建模 M0～M7 实施方案

_本文仅列出 M0～M7 各阶段的建模实施内容、交付物与完成门槛；各阶段按顺序推进，前一阶段通过后再进入下一阶段。_

---

## 📋 M0：模型契约与工程骨架

### 阶段目标

固定模型边界、数据结构、单位体系、配置格式和版本规则，为后续设备模型提供统一基础。

### 实施内容

- 建立 `src/petroleum_rto/cdu/`、`configs/`、`tests/` 和 `runs/` 的建模目录结构。
- 定义 6 个烃类伪组分以及水、盐示踪，记录名义沸点、密度、比热、汽化潜热、参数来源和置信度。
- 定义 `MaterialStream`、`UnitResult`、`EquipmentState`、`ControlSignals`、`SimulationResult` 和 `BalanceReport` 等核心对象。
- 统一内部 SI 单位；仅在配置输入和结果展示边界进行 `t/h`、`℃`、`MPa` 等单位转换。
- 建立模型参数、工况案例和扰动场景的配置格式，并实现字段、范围、单位和必填项校验。
- 分离软件版本、模型结构版本、参数集版本、配置版本和案例版本。
- 实现限幅、归一化、流股混合、数值求根和 RK4 等通用数值工具。
- 为负流量、非有限值、组成不闭合、配置缺项和单位错误建立明确的异常处理。

### 阶段交付物

- 核心数据对象与单位转换模块。
- 伪组分物性参数模板。
- 模型、案例和场景配置模板。
- 数值工具与配置校验模块。
- 核心对象、流股混合和异常输入测试。

### 完成门槛

- 所有核心对象可以由配置完整构造并序列化输出。
- 质量分数非负且归一化，流量、温度和压力均为有限值。
- 流股混合前后总质量和各组分质量在数值容差内闭合。
- 非法输入被明确拒绝，不以静默修正掩盖错误。
- 同一配置和版本组合能够生成一致的模型输入。

## ⚙️ M1：开环稳态设备链

### 阶段目标

建立从原油进料到各产品边界的开环稳态流程，使每台关键设备具有可解释的输入、输出和守恒结果。

### 实施内容

- 建立等效预热器，以换热效率和目标温度计算出口温度与回收热量。
- 建立等效电脱盐器，计算脱水、脱盐以及注水对后续物流的影响。
- 建立平滑汽液分配闪蒸模型，使汽化率随温度、压力和组成连续变化。
- 建立常压炉稳态热平衡，计算燃料热负荷、炉效率、散热损失和炉出口温度。
- 建立缩减阶常压塔，以切割点、分离锐度和产品分配矩阵计算塔顶、常一、常二、常三和渣油物流。
- 建立塔顶冷凝器与三相分离，输出不凝气、含油冷凝液和水相。
- 建立汽油、常一、常二、常三和渣油的收率、密度、馏程及闪点方向性代理指标。
- 串联开环流程，并对设备级和全流程级物料、组分及声明范围内的能量进行核算。

### 阶段交付物

- 预热器、脱盐器、闪蒸器、常压炉、缩减阶常压塔和塔顶冷凝器模型。
- 开环稳态流程组装器。
- 设备结果、产品结果和全流程衡算报告。
- 各设备边界、方向性和守恒测试。

### 完成门槛

- 每台设备和全流程的总质量、组分质量在设定数值容差内闭合。
- 所有产品流量和组成非负，产品分配矩阵各组分列和为 1。
- 升高闪蒸温度不降低汽化率，升高炉负荷不降低炉出口温度。
- 移动切割点或改变分离锐度时，产品收率和质量代理的变化方向符合模型定义。
- 基准案例能够输出有限、可解释且可重复的完整稳态结果。

## 🔄 M2：物理循环与稳态闭合

### 阶段目标

在开环设备链上加入真实回流和等效热回收，使系统形成可收敛的物理循环。

### 实施内容

- 将塔顶含油冷凝液按回流比拆分为汽油产品和塔顶回流。
- 将塔顶回流重新接入常压塔入口边界，并更新塔内有效汽液负荷与产品分配。
- 设置回流撕裂变量，采用欠松弛迭代求解循环流量、组成和温度。
- 设置迭代容差、最大迭代次数、松弛因子和初值策略。
- 将顶循、一中和二中的取热作用缩减为等效热负荷，并反馈至原油预热和常压炉热负荷。
- 区分装置内部循环流量与新鲜进料、净产品边界，重新计算净物料和净能量衡算。
- 输出收敛状态、迭代次数、最终残差、失败原因和最后有效迭代状态。

### 阶段交付物

- 塔顶冷凝—回流循环模型。
- 等效循环取热—原油预热反馈模型。
- 稳态循环求解器与收敛诊断。
- 循环收敛、净边界守恒和不收敛测试。

### 完成门槛

- 基准案例及其邻域工况在规定迭代次数内达到流量、组成和温度收敛容差。
- 新鲜进料与全部净出口在数值容差内满足物料衡算。
- 增大回流比、循环取热或预热效率时，相关温度、炉负荷和产品分布的响应方向合理。
- 对不合理初值和不可收敛参数返回明确失败状态，不输出伪造的有效结果。
- 相同初值、参数和配置得到一致的收敛结果。

## ⏱️ M3：开环动态装置

### 阶段目标

在已收敛稳态流程上加入必要的库存、热容、压力和设备滞后，形成可积分且与稳态一致的开环动态对象。

### 实施内容

- 建立闪蒸罐、回流罐和塔底的总量、组分与盐库存状态；三条侧线保持为不含额外容器的代数采出流。
- 建立常压炉有效热容及炉出口温度动态。
- 建立塔顶气相组分库存，由固定气相体积和理想气体关系派生绝压，并建立塔顶、侧线温度的一阶响应。
- 建立换热器、冷凝器和循环取热负荷的一阶动态。
- 建立一阶传感器和执行机构模型；通用模块支持测量滞后、开度上下限、变化速率限制和失效位置，但具体设备只启用有版本化资料支撑的限制，当前 CDU 方程不从名义点臆造现场行程或速率边界。
- 使用固定名义输出网格的 RK4 积分动态方程；在非网格命令事件起止处确定性拆分子步，并在每个子步更新物性、设备状态、库存和约束。
- 从 M2 稳态解一致初始化所有动态状态，使零扰动时各状态导数接近零。
- 输出统一时间序列、设备状态、库存变化、动态衡算、五个净烃产品组成/质量观察和数值诊断，并强制标识为合成仿真数据。

### 阶段交付物

- 动态状态方程与 RK4 仿真引擎。
- 动态设备、传感器和执行机构模块。
- 稳态一致初始化器。
- 开环阶跃场景与时间序列输出器。
- 动态库存、稳态保持和时间步长敏感性测试。

### 完成门槛

- 稳态初始化后的零扰动运行不出现明显漂移，初始状态导数满足设定容差。
- 所有库存、流量、温度和压力始终有限，库存不出现负值。
- 各操纵量小阶跃引起的响应连续、有界，且方向符合设备模型定义。
- 动态物料积存与进出口流量在数值容差内一致。
- 时间步长减半后，关键状态和稳态终值的归一化差异不超过验收阈值。
- 相同初值、时间步长和配置产生可重复的时间序列。

## 🎛️ M4：PI 控制闭环

### 阶段目标

在 M3 动态对象上加入最小必要控制回路，完成闭环整定和首条端到端扰动恢复场景。

### 实施内容

- 建立带输出限幅、变化率限制、抗积分饱和、设定值斜坡、手自动切换和无扰切换的 PI 控制器。
- 实现原油进料流量—进料阀、闪蒸罐液位—炉前流量、炉出口温度—燃料热负荷控制回路。
- 实现塔顶压力—不凝气阀、回流罐液位—汽油采出、塔底液位—渣油采出控制回路。
- 实现塔顶温度—等效顶循取热控制回路；回流量保持独立设定，避免与液位或压力回路争用操纵量。
- 仅在显式建立侧线汽提塔库存时，增加侧线汽提塔液位—侧线采出控制回路。
- 为炉温控制加入基于炉前流量的热负荷前馈，并由 PI 修正稳态偏差。
- 从 M3 稳态状态初始化执行机构位置和 PI 积分项。
- 按流量、压力、炉温、液位和塔顶温度的顺序逐回路整定。
- 建立“基准稳定保持—进料设定值增加 5%—闭环恢复”的标准场景。
- 计算跟踪误差积分、超调量、稳定时间、最终偏差、饱和时间和最大约束偏差。

### 阶段交付物

- PI 控制器与控制回路组装模块。
- 冻结的首版被控量—操纵量配对表。
- 控制器初始整定参数集。
- 基准保持与进料 `+5%` 阶跃场景。
- 闭环性能指标和验收报告。

### 完成门槛

- 从稳态切换到自动控制时无明显控制冲击。
- 基准保持阶段末段的主要变量斜率和控制偏差低于配置阈值。
- 进料阶跃后，主要被控量在规定时长内回到各自允许带。
- 所有液位保持在设定安全区间，且末段不存在持续振荡或持续执行机构饱和。
- 任一操纵量只由一个主回路直接控制，不存在未处理的控制器争用。
- 仿真期间无非有限值、负库存或未处理的硬约束越界。

## 🔍 M5：基准校正与数据协调

### 阶段目标

利用现有单套现场资料协调基准工况，并校正少量可辨识的稳态参数。

### 实施内容

- 将现有流量、温度、压力、产品收率和弱时间对齐化验值整理为 `case_20260604` 基准案例。
- 为每个观测值记录来源、单位、时间基准、读取方式、可信度和允许误差。
- 对同一物料边界内的流量进行数据协调，保留原始值、协调值、调整量和衡算残差。
- 划分固定参数、可校正参数和暂不可辨识参数，禁止用单一案例同时拟合全部参数。
- 校正预热效率、炉效率与热损失、闪蒸锐度、塔切割点、分离锐度、回流影响和质量代理修正系数中的可辨识子集。
- 建立带测点权重、参数边界和正则约束的残差目标函数。
- 检查参数局部灵敏度、相关性和边界命中情况。
- 对缺少连续 DCS 支撑的动态时间常数保留工程初值，不作现场动态拟合。
- 保存校正前后误差、未参与校正的数据和参数集版本。

### 阶段交付物

- 结构化 `case_20260604` 基准案例。
- 数据协调结果及物料衡算记录。
- 参数边界、测点权重和校正配置。
- 版本化校正参数集。
- 校正前后误差与参数审查报告。

### 完成门槛

- 所有参与校正的数据均具有来源、单位、时间基准和可信度记录。
- 程序内部守恒仍达到数值容差，不以破坏守恒换取现场数据拟合。
- 可比时间基准下的现场表观物料偏差目标不超过 3%；时间基准不明确的数据不作为强制通过项。
- 校正后加权误差相对初始参数下降。
- 所有校正参数位于物理边界内，命中边界的参数均有审查记录。
- 校正结果能够由案例版本、模型版本和参数版本完整复现。

## 🧪 M6：验证、不确定度与适用域

### 阶段目标

系统验证模型的守恒、方向性、动态响应和异常处理，并给出参数不确定度、适用范围和越域拒绝规则。

### 实施内容

- 建立设备级、流程级、稳态、动态、控制和回归测试矩阵。
- 对进料负荷、原油伪组分、进料温度、燃料热值、冷却能力、汽提蒸汽、回流比和循环取热执行单因素扰动。
- 建立正常扰动场景：进料 `±5%`、原油轻重端变化、入口温度变化、燃料热值下降和冷却能力下降。
- 建立异常场景：含水脉冲、进料骤降、循环泵停运、燃料负荷饱和、传感器偏置和阀门卡涩。
- 建立低炉前流量、高炉出口温度、高塔顶压力、高低液位、泵停运和测量失效的仿真保护状态机。
- 为保护逻辑加入触发延迟、回差、锁存、复位和控制器跟踪。
- 对关键参数执行局部敏感性和区间传播，输出产品收率、能耗、质量代理和动态指标的不确定区间。
- 定义模型输入适用域、越域距离、拒绝原因和降级结果。
- 输出事件时间线、保护动作、约束越界、恢复状态和验证证据。

### 阶段交付物

- 自动化验证矩阵与回归场景集。
- 正常扰动、异常和保护场景库。
- 仿真保护状态机与事件记录。
- 参数敏感性和输出不确定度报告。
- 模型适用域与拒绝规则。

### 完成门槛

- 每项模型能力声明均有对应的自动测试或场景证据。
- 所有场景均可确定性复现，且具有明确的通过、受限、拒绝或失败状态。
- 保护条件达到时按设定延迟触发，并在回差区间内不发生状态抖动。
- 越出适用域的输入被明确拒绝或降级处理，不返回无标识的正常结果。
- 输入可信度降低或参数范围扩大时，输出不确定区间不会反向缩小。
- 无效结果与有效结果严格隔离，失败原因完整保留。
- 仿真保护逻辑仅用于模型行为验证，不宣称复刻或验证现场 SIS。

## 📦 M7：模型封装与可复现交付

### 阶段目标

将通过验证的模型封装为稳定、可调用、可追溯的独立仿真组件，完成本轮建模工作交付。

### 实施内容

- 冻结 Python 调用接口和命令行运行入口，统一稳态、动态和场景运行方式。
- 冻结输入配置、时间序列、设备结果、产品结果、事件和错误状态的输出格式。
- 为每次运行生成唯一标识、配置哈希和运行清单。
- 在运行清单中记录代码版本、模型结构版本、参数集版本、案例版本、随机种子和运行环境。
- 支持基准案例、进料阶跃、正常扰动和异常场景的一键运行。
- 支持单案例失败隔离、批量场景顺序运行和中断后继续。
- 编写模型卡，说明建模边界、方程层级、已验证能力、已知限制、适用域和禁止用途。
- 编写输入数据字典、配置示例、结果字段说明和复现实例。
- 记录代表性场景的运行时间、内存占用和数值步长，形成性能基线。
- 固化发布前检查，覆盖测试、版本、配置、结果追溯和文档一致性。

### 阶段交付物

- 稳定的 Python API 与命令行入口。
- 版本化模型包和默认参数集。
- 标准输入、输出与运行清单格式。
- 基准、扰动和异常复现实例。
- 模型卡、数据字典和使用说明。
- 发布检查清单与性能基线。

### 完成门槛

- 全部单元、守恒、集成、动态、控制、场景和回归测试通过。
- 基准案例、进料 `+5%` 场景及选定异常场景能够通过统一入口完整复现。
- 每个结果均可追溯到代码、模型、参数、案例、配置和运行环境版本。
- 失败运行保留完整错误状态，不覆盖已有有效结果。
- 在项目规定的干净 Python 环境中能够按使用说明完成安装、运行和结果读取。
- 模型卡与实际实现一致，明确声明数据稀缺导致的精度限制和禁止用途。
