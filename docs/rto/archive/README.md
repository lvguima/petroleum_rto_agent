## 📋 归档边界

1. [RTO系统综合说明](../01_RTO系统综合说明.md)：现行职责、统一合同、迁移状态和删除门禁
2. [RTO离线运行与策略库使用说明](../04_RTO离线运行与策略库使用说明.md)：当前仍可执行的历史V1/V2命令、恢复和治理方式
3. [项目实施状态](../../STATUS.md)：当前授权、验证、风险和下一步的唯一进度来源

> ⚠️ **声明边界：** 归档文档中的V1/V2名称、profile依赖和双轨workflow只描述历史实现，不代表统一目标架构继续按目标数量分版本。
