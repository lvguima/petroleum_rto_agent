## 📋 决策背景

用户已授权开始RTO并先实现R0、R1和R2。本记录把此前实施方案中的V1建议值正式冻结为版本化、可执行的工程政策，使后续合同、编译器和求解器不再依赖散落在文档中的默认值。

> ⚠️ **声明边界：** 本记录中的局部范围、质量代理、收率门槛、动态验收和发布改善率均为合成工程政策，不是现场安全范围、产品标准、MOC结论或可下装控制指令。

## 🎯 冻结决策

### 目标与优先级

| 项目 | 冻结值 |
| --- | --- |
| 优化模式 | 单目标最小化 |
| 目标 | `specific_furnace_fuel_energy_mj_per_t` |
| 准确含义 | 单位进料炉燃料热负荷代理 |
| 硬门禁顺序 | 可评价性 → M4稳定性 → 质量代理保持 → 有价值馏分收率保持 |
| 发布门禁 | 单位进料炉燃料代理改善不低于`0.5%` |
| 输出 | 绝对高层稳态设定值向量 |

目标公式为：

```text
furnace_fuel_duty_w / feed_mass_flow_kg_s / 1000
```

当前基准`21,312,989.029536318 W`和`407.3 t/h`对应`188.378985 MJ/t`。该指标不包含全装置电、蒸汽、冷却或产品价格，不能改称完整装置能耗或经济利润。

### 决策变量与上下文

| 变量 | 角色 | 规范范围 | 粗步长 | 细步长 | M2映射 | M4映射 |
| --- | --- | ---: | ---: | ---: | --- | --- |
| 炉出口温度目标 | 决策 | `626.35～630.35 K` | `1 K` | `0.5 K` | `operating.furnace_outlet_temperature_c` | `furnace_temperature.setpoint_ratio` |
| 塔顶压力目标 | 决策 | `150325～154325 Pa(a)` | `1000 Pa` | `500 Pa` | `operating.tower_top_pressure_mpa_g` | `top_pressure.setpoint_ratio` |
| 新鲜原油进料 | 固定上下文 | 名义`113.1388889 kg/s` | — | — | `feed.mass_flow_t_h` | 不作为RTO动作 |
| 回流比 | 延后 | — | — | — | M2可用 | 当前没有对应高层SP |

炉温显示范围等价于`353.2～357.2 ℃`，塔顶压力显示范围等价于`0.049～0.053 MPa(g)`。显示单位只用于人机接口；候选指纹、边界判断和配对缓存统一使用K、Pa(a)和kg/s。

### 约束和采样

| 优先级 | 规则 | 冻结值 | 类型 |
| ---: | --- | ---: | --- |
| 0 | M2结构与数值可评价 | 成功、收敛、守恒、有限、非负 | 硬门禁 |
| 1 | M4稳定性 | 复用现有`acceptance_passed=true`及控制指纹 | 硬门禁 |
| 2 | 质量代理保持 | 八项选定密度/T50代理的最大绝对相对变化`≤0.5%` | 硬门禁 |
| 3 | 有价值馏分收率 | 汽油、煤油、轻柴、重柴合计收率差`≥-0.002` | 硬门禁 |
| 4 | 能耗代理改善 | 相对基准改善`≥0.5%` | 可发布性门禁 |

质量门禁采用“保持”而不是人为指定改善方向，因为当前缩减模型代理尚不能代替产品规格。相对变化计算必须处理零或极小基准分母，不能产生`NaN`或`Inf`。

进料声明范围只使用`0.95/1.00/1.05`三个离散锚点，即`386.935/407.3/427.665 t/h`。三点全部通过只能声明`sampled_anchors`，不证明连续区间。

### 评价计划

| 项目 | 冻结值 |
| --- | --- |
| M2 preset | `steady-baseline` |
| M4 preset | `closed-loop-feed-step` |
| M4切换时刻 | `600 s` |
| M4时域/步长 | `7200 s / 1 s` |
| 动态短名单 | Top-3 |
| 首版执行方式 | 同步、单进程、离线 |
| 暂不引入 | Redis、消息队列、代理模型、HYSYS、负案例策略库 |

## 🔍 字段来源与可提取性

| KPI或门禁 | 当前证据路径 | 评价层 |
| --- | --- | --- |
| 炉燃料热负荷 | `summary.flowsheet.diagnostics.furnace_fuel_duty_w` | M2 |
| 新鲜原油流量 | `summary.flowsheet.streams.fresh_crude.mass_flow_kg_s` | M2 |
| 四类有价值馏分收率 | `summary.flowsheet.diagnostics.*_yield_mass_fraction` | M2 |
| 八项质量代理 | `summary.flowsheet.qualities.<product>.density_kg_m3_proxy/t50_k_proxy` | M2 |
| 执行、收敛和守恒 | `runtime_status`、`engine_status`、`summary.flowsheet.balance` | M2 |
| 闭环稳定性 | `summary.acceptance_passed`及`summary.control_fingerprint` | M4 |

R2的真实M2适配器测试逐路径读取全部直接M2字段；R4继续复用已经冻结的M7/M4验收合同，只读取`acceptance_passed`、既有检查、回路性能和控制指纹，不重复实现PI或动态验收。

## ⚡ 影响与风险

### 正面影响

- R1可以从确定配置生成唯一优化问题和指纹
- R2可以对两个决策量建立真实M2/M4端到端映射
- 未来垂域模型只需输出同一`OptimizationIntentV1`合同

### 保留风险

| 风险 | 处理 |
| --- | --- |
| 模型低可信 | 全部对象固定`engineering_simulation_only` |
| 质量代理不等于规格 | 只做相对保持，不声称产品放行 |
| 局部范围未现场确认 | 配置标记`synthetic_local_range` |
| 三锚点不能代表连续区间 | 查询只匹配显式锚点 |
| 回流比没有M4高层SP | 保持延后，不伪造端到端映射 |
