## RTO与策略库

- [RTO系统综合说明](rto/01_RTO系统综合说明.md)
- [垂域模型与RTO通信协议](rto/02_垂域模型与RTO通信协议.md)

RTO只有一套覆盖`1..N`目标的执行链。普通运行生成内存摘要和简洁`result.json`，其中可列出推荐方案以外的候选及其M2/M4验证状态，但不自动创建策略；开发者严格检查与正式策略治理保持为独立路径。

## 本地领域Agent

- [本地领域Agent说明](domain_model/01_聚合式垂域模型综合说明.md)
- [垂域模型与RTO通信协议](rto/02_垂域模型与RTO通信协议.md)

Agent使用LLM闭集语义路由，不要求用户命中关键词模板。严格意图解析后，程序按已校验意图和当前能力生成确认摘要；整句只有“确认”或“取消”时本地直达，其他回复由小范围分类处理。没有具体目标的泛化优化请求会得到目标、变量和表达示例引导。确认后才读取最新受信工况并运行离线RTO；回复直接来自内存结果，`/result`只轻量读取当前七字段结果文件。
